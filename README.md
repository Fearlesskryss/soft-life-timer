# ✨SOFT LIFE TIMER** 

A cute desktop productivity time built with Electon, HTML, CSS, and JavaScript. This project was created as a hands-on project to practice JavaScript fundamentals , desktop application development, and Git/GitHub version control.
## ✨ FEATURES
-**Start** the timer

-**Pause** the timer

-**Reset** the timer

-Choose from preset time durations

-Automatic countdown display

-Completion message when timer ends

-Simple, playful productivity-focused interface 

## ✨ DESIGN

Soft Life Timer was designed with a **short,playful aesthetic** to make productivity feel a little more enjoyable.

- **HTML** — application structure

## 🚀 How to use

### 1. Clone This Repo

```bash
git clone https://github.com/Fearlesskryss/soft-life-timer.git
cd soft-life-timer

2. Install Dependencies
Bash
npm install

3. Start the Application
Bash
npm start

4. Choose Your Timer
Select a preset and click start to begin the countdown

Use pause to pause the timer or reset to begin the countdown
